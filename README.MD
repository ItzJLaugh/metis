Metis 

--------------------------------------------------------------------------------------

A ultra fast system that connects to your AI model to...

- Search for files faster
- Automatically sort files in folders or create a new folder (/srv/...)
- Burn WAY less tokens for file search

--------------------------------------------------------------------------------------

Run these commands in your WSL/Linux terminal:

1. git clone https://github.com/ItzJLaugh/metis.git
2. cd metis
3. sudo ./install.sh
